# RFC 0002: Application identity transition (child of 0001)

**Status:** Superseded

**Superseded by:** RFC 0004.

**Parent:** [0001](../completed/0001-karen-system-resource-app.md)

## Summary

This proposal covered the desktop product identity and compatibility during the original migration. RFC 0004 replaced its compatibility requirements with the Karen CLI, Tauri, and Vue architecture.

## Problem

The expanded system monitor required a product identity and desktop architecture that covered disk, CPU, and memory workflows.

## Goals

Use Karen consistently for the product, command, desktop bundle, and release artifacts.

## Superseded design

The original proposal retained prior command, package, installation, and macOS bundle identities. RFC 0004 explicitly replaces that approach. This archived record does not define current naming or compatibility requirements.

## Acceptance

Superseded by RFC 0004; no implementation remains in scope.
